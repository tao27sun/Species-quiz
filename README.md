# 物种识别考试

Windows 本地运行，浏览器答题。运行时不联网，物种名称以 Excel A 列中的原文为准。

## 首次使用

1. 安装 Python 3.10 或更新版本。
2. 双击 `install.bat`，等待依赖安装完成（首次安装需要联网）。
3. 双击 `start.bat`，默认浏览器自动打开 `http://127.0.0.1:5000`。

日常只需双击 `start.bat`。关闭启动时的命令行窗口或按 Ctrl+C 即可结束程序；关闭浏览器不会关闭程序。

## 免安装 Python 的 Windows 版本

当前项目目录内有 `build.bat`。在已安装 Python 的构建电脑上先运行 `install.bat`，再双击 `build.bat`，会生成 `release\SpeciesQuiz-Windows-x64.zip`。把压缩包复制到其他 **Windows 64 位** 电脑并完整解压，双击其中的 `SpeciesQuiz.exe` 即可；运行电脑不需要 Python。

压缩包中的 `species.xlsx` 是独立题库。更新时只需关闭程序、替换 EXE 旁的 Excel、重新启动。macOS 或 Linux 需要分别在对应系统上构建，Windows 包不能直接运行。

## 题库

源码运行所需的 `species.xlsx` 可从 GitHub Release 的 Windows 便携包中取得，解压后将它放在项目根目录。

维护根目录中的 `species.xlsx`，启动后先选择题库，再选择复习或测试，按名称读取对应工作表（8年级植物：`Plants 8`，8年级鸟类和哺乳动物：`Birds&Mammals 5-8`，9年级鸟类和哺乳动物：`Birds&Mammals 5-9`）：A 列是名称，B 列以后是 Excel“单元格内图片 / Place in Cell”，每格一张、每行至少一张。支持无表头；首个非空行明确为“物种名称 / 图片1 / 图片2……”时自动跳过；旧题库的“芬兰语名称”表头也兼容。普通缺图行会报错。传统浮动图片不在支持范围内。

修改题库后保存，关闭程序，再运行 `start.bat`。不要用会丢失单元格内图片的软件重新保存题库。程序只读取文件，不会改写 Excel。

题目和图片取自所选工作表。数量由程序读取，不写死在程序中；测试中的样本数量断言对应本次提供的文件。重复图片引用仍受支持，会分别保留。

## 答题

复习按随机顺序展示图片和答案，按 Enter 或点击按钮进入下一题。测试沿用以下流程。

- 每轮随机覆盖所有物种。输入框自动聚焦，Enter 提交，再按一次进入下一题。
- `ä / ö / å` 按钮在光标位置插入字符。只忽略答案的大小写及首尾空白；内部空格、连字符及特殊字母必须准确。
- 空答案可提交，判为错误。提交后锁定答案，并显示正确答案。
- 点击图片放大，Esc 或点击背景关闭。
- 最后一题提交后点击“查看成绩”，查看全部错题。成绩页可再练一次或选择其他题库。答题中途返回选择页时需确认放弃本轮。
- 刷新保留当前进度；关闭程序后不保存答题记录。多个标签页共享同一轮考试。

## 常见问题

题库错误会显示中文错误页，请按行号或单元格提示修复并重新启动。端口 5000 被占用时，关闭之前的程序再启动。安装或启动失败会保留控制台错误信息。服务只监听本机，不提供局域网访问。
